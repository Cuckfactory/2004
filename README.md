# SIGNED IN

A 2004 desktop that still has your number.

MSN Messenger + Winamp + Minesweeper + a late-night tycoon loop, running inside a painterly XP machine. Keep your buddy list alive until dawn. Memory is the currency. Dawn is the tax.

## Run

Open `index.html` in a browser (double-click it), or from this folder:

```
python3 -m http.server 8765
```

then visit http://localhost:8765

Click once so the machine is allowed to make sound.

## How to stay

- Talk. Contacts go away, then offline, if you ignore them.
- Match Winamp genre to a name (emo / nu-metal / pop / ambient / idm) and they linger.
- Spend Memory in **Night Ledger.exe**.
- Restore `old_screenname` from the Recycle Bin when you can afford to remember.
- Solitaire is real Klondike (click, then click a pile; double-click to the suit stack).
- Minesweeper is real 9×9. First click is safe. Double-click a number to chord.
- Walk away ~55 seconds: Windows 3D Pipes.
- Quote.com is a 1998 after-hours ticker. Under the woodgrain it is DexScreener — paste a CA when the token exists.
- Sign Out from Start if you want a clean night.

The night persists in localStorage.

## Live pit

Deploy `worker/` with `npx wrangler deploy`. Paste the URL in Quote.com.
Two machines on the same pair then see the same “3 signed in” count.
